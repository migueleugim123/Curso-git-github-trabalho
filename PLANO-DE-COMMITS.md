# Plano de commits

A atividade exige pelo menos seis commits atômicos. Sugestão:

1. `docs: adiciona README inicial`
2. `docs: adiciona introdução ao HTML`
3. `docs: adiciona conceitos fundamentais`
4. `feat: adiciona exercícios do guia`
5. `docs: adiciona referências e exemplo básico`
6. `docs: adiciona reflexão final`
7. `fix: resolve conflito no README`
8. `docs: registra evidências do projeto`

Cada commit deve representar uma alteração clara e pequena.
