# HTML para Iniciantes

## Objetivo

Este guia apresenta os conceitos fundamentais de HTML de forma simples e sequencial. O objetivo é ajudar iniciantes a compreender a estrutura de uma página web e criar seus primeiros documentos HTML.

## Público-alvo

Estudantes e iniciantes em programação e desenvolvimento web que possuem pouco ou nenhum conhecimento prévio de HTML.

## Pré-requisitos

- Conhecimentos básicos de informática.
- Um editor de texto ou IDE, como VS Code.
- Um navegador web.
- Git instalado para acompanhar o projeto.

## Como navegar

A recomendação é seguir os módulos na ordem apresentada. Primeiro, conheça o que é HTML; depois, estude seus principais elementos; em seguida, pratique com exercícios e consulte as referências.
